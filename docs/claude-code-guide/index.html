Biến Claude Code thành xưởng sản xuất video ngắn với MoneyPrinterTurbo

MoneyPrinterTurbo (MPT) nhận một chủ đề rồi tự động viết kịch bản, tìm footage, lồng tiếng, tạo phụ đề, ghép nhạc nền và xuất video HD. Trang này chỉ cách giao toàn bộ quy trình đó cho Claude Code: cài đặt, cấu hình, tạo video, chạy hàng loạt, sửa lỗi và đăng lên mạng xã hội.

Dựa trên mã nguồn v1.3.10 Python 3.11+ · uv · FFmpeg CLI · API · WebUI · Skill

1Tổng quan: Claude Code giúp được gì?

Claude Code có thể tham gia MoneyPrinterTurbo theo hai vai trò, dùng riêng hoặc kết hợp:

Vai trò A

Người vận hành (agent)

Claude Code đọc repo, cài môi trường, sửa config.toml, chạy cli.py hoặc gọi API, chờ kết quả, đọc log khi lỗi và trả về đường dẫn file MP4.

Vai trò B

Bộ não viết kịch bản (LLM)

Provider claude_code cho phép MPT gọi claude -p để viết kịch bản bằng gói Claude Pro/Max/Team của bạn, không cần API key.

MPT có 4 cách sử dụng. Với Claude Code, nên ưu tiên theo thứ tự này:

CáchKhi nào dùngClaude Code làm gì
Skill (docs/skill)Muốn có video nhanh nhất, không cần biết kỹ thuậtChạy mpt_agent.py: tự cài đặt, hỏi key còn thiếu, trả về MP4
CLI (cli.py)Cần kiểm soát mọi tham số, chạy hàng loạt, tự động hoáGhép lệnh từ yêu cầu của bạn, chạy, đọc JSON kết quả

2Chuẩn bị

  1. Cài Claude Code và đăng nhập (claude trong terminal). Tài liệu: code.claude.com/docs.
  2. Lấy mã nguồn. Clone repo rồi mở Claude Code trong thư mục đó: 
    git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
claude
    Hoặc cài gói pip chính chủ mpt (không cần clone): python -m pip install mpt, sau đó dùng mpt webui / mpt cli --help.
  3. Giao việc cài đặt cho Claude: 
    Đọc README-en.md và pyproject.toml. Cài môi trường bằng uv (Python 3.11, uv sync --frozen), kiểm tra FFmpeg đã có chưa, rồi chạy `uv run python cli.py --help` để xác nhận mọi thứ hoạt động. Đừng tự sửa config.toml khi chưa hỏi tôi.
  4. Chuẩn bị API key tối thiểu: một LLM (hoặc dùng gói Claude, xem mục 7) và một nguồn footage (ví dụ Pexels, miễn phí). Giọng đọc Edge TTS miễn phí, không cần key.

3Cách nhanh nhất: dùng Skill có sẵn

Repo có sẵn một Agent Skill tại docs/skill/SKILL.md, kèm script hỗ trợ mpt_agent.py. Skill này hướng dẫn agent tự cài MPT vào ~/MoneyPrinterTurbo, dùng lại cấu hình sẵn có, chạy CLI, chờ xong và trả về file MP4. Skill chính thức hỗ trợ macOS và Windows.

3.1 Dùng ngay qua URL

Use this Skill: https://raw.githubusercontent.com/harry0703/MoneyPrinterTurbo/main/docs/skill/SKILL.md
Tạo một video tiếng Việt, khổ dọc 9:16, chủ đề "5 thói quen buổi sáng giúp bạn làm việc hiệu quả", giọng vi-VN-HoaiMyNeural-Female, có phụ đề và nhạc nền.

3.2 Cài Skill vĩnh viễn vào Claude Code

Chép thư mục Skill vào thư mục skills cá nhân để Claude tự nhận diện mỗi khi bạn nhắc tới việc làm video:

macOS / Linuxmkdir -p ~/.claude/skills/moneyprinterturbo-video
cp docs/skill/SKILL.md docs/skill/mpt_agent.py ~/.claude/skills/moneyprinterturbo-video/

Muốn cả team dùng chung thì đặt vào .claude/skills/moneyprinterturbo-video/ trong repo dự án. Sau đó chỉ cần nói: “Làm cho tôi video về chủ đề …”.

4Điều khiển trực tiếp bằng CLI

CLI là giao diện mạnh nhất để Claude Code điều khiển: mọi tham số đều có cờ dòng lệnh, kết quả in ra dạng một đối tượng JSON trên stdout (log nằm ở stderr), file đầu ra nằm ở storage/tasks/<task-id>/.

uv run python cli.py --video-subject "Vì sao giấc ngủ quan trọng" \
  --video-language vi --voice-name vi-VN-HoaiMyNeural-Female \
  --font-name BeVietnamPro-Bold.ttf --video-aspect 9:16

Thứ tự ưu tiên giá trị: cờ CLI > giá trị đã lưu trong [ui] của config.toml > mặc định (áp dụng cho phụ đề và giọng đọc).

Khi xong, cho tôi đường dẫn các file MP4.

5Pipeline và chạy từng bước với --stop-at

script→terms→audio→subtitle→materials→video

--stop-at <stage> dừng ngay sau bước đã chọn và in kết quả của bước đó. Cách này rất hợp với Claude Code: duyệt kịch bản trước, chỉnh sửa, rồi mới tốn thời gian render.

Bước 1: chạy cli.py với --stop-at script cho chủ đề "Bí quyết chụp ảnh đẹp bằng điện thoại" (tiếng Việt). Cho tôi xem kịch bản.
Bước 2: sau khi tôi duyệt và sửa, chạy lại toàn bộ với --video-script "" để xuất video.
Mã thoát CLIÝ nghĩa
0Thành công, in một đối tượng JSON trên stdout
1Task bị lỗi khi chạy
2Sai tham số hoặc manifest; dừng trước khi bắt đầu

6Sản xuất hàng loạt với --batch-file

Truyền một file JSON (mảng) hoặc JSONL. Cờ CLI đóng vai trò giá trị mặc định, mỗi object ghi đè các trường của VideoParams. Giới hạn: 100 task và 1 MiB mỗi manifest. Mọi task được kiểm tra hợp lệ trước khi chạy, task lỗi không làm dừng các task còn lại, cuối cùng in một bản tóm tắt JSON (total, succeeded, failed, tasks).

tasks.jsonl{"video_subject": "Lợi ích của việc đọc sách mỗi ngày"}
{"video_subject": "Cách pha cà phê phin chuẩn vị", "video_aspect": "16:9"}
{"video_subject": "3 địa điểm du lịch Đà Lạt", "voice_name": "vi-VN-NamMinhNeural-Male"}
uv run python cli.py --batch-file ./tasks.jsonl --video-language vi \
  --voice-name vi-VN-HoaiMyNeural-Female --font-name BeVietnamPro-Bold.ttf
Lên ý tưởng 20 chủ đề video ngắn cho kênh TikTok về tài chính cá nhân, ghi thành tasks.jsonl (mỗi dòng một video_subject, tiếng Việt). Chạy cli.py --batch-file với giọng vi-VN-HoaiMyNeural-Female, rồi tổng hợp bảng: chủ đề, trạng thái, đường dẫn video, lỗi (nếu có). Task nào lỗi thì phân tích nguyên nhân và chạy lại riêng.
Đường dẫn tương đốicustom_audio_file và video_materials[].url trong manifest được tính theo thư mục chứa manifest. Đường dẫn truyền bằng cờ CLI thì tính theo thư mục hiện tại.

7Dùng gói Claude (Pro / Max / Team) làm LLM viết kịch bản

Gói thuê bao Claude không cấp API key, nên MPT có sẵn provider claude_code. Provider này gọi claude -p ở chế độ headless (tắt mọi công cụ, CLAUDE.md, skills, hooks và MCP) và tính vào hạn mức gói thuê bao của bạn. Cần Claude Code CLI phiên bản 2.1.260 trở lên.

7.1 Chạy trực tiếp trên máy

config.toml → [app]llm_provider = "claude_code"
claude_code_model_name = ""   # để trống = model mặc định của CLI; hoặc "claude-sonnet-5", "claude-opus-5"
claude_code_cli_path = ""     # để trống = tìm `claude` trong PATH
claude_code_timeout = ""      # để trống = 300 giây

Chỉ cần claude đã đăng nhập trên máy. Bạn cũng có thể chọn “Claude Code (Claude subscription)” trong phần cài đặt LLM của WebUI.

7.2 Chạy bằng Docker

Trong container không có keychain, nên phải dùng token dài hạn. Repo đã có sẵn Dockerfile.claude (cài Node 22 và @anthropic-ai/claude-code) cùng docker-compose.claude.yml:

export CLAUDE_CODE_OAUTH_TOKEN="$(claude setup-token)"
docker compose -f docker-compose.claude.yml up -d --build
# WebUI: http://127.0.0.1:8501   ·   API: http://127.0.0.1:8080/docs
Biến môi trường xung độtTrước khi gọi CLI, MPT tự xoá các biến ANTHROPIC_* và CLAUDE_CODE_USE_* để chắc chắn dùng gói thuê bao. Nếu muốn trả theo API key, hãy dùng provider anthropic với anthropic_api_key.

8Các nhà cung cấp LLM khác

Đặt llm_provider trong config.toml và điền key tương ứng (<provider>_api_key, có thể kèm _model_name và _base_url). Một số provider phổ biến:

Trả theo API

moonshot (Kimi, mặc định), openai, anthropic, gemini, deepseek, qwen, azure, volcengine, grok, minimax, mimo

Gateway / tổng hợp

OpenRouter, AIHubMix, Shengsuan Cloud, APIMart, Infistar, Jalapeno, OFox, Cloudflare AI Gateway, LiteLLM, OneAPI, Groq…

Đăng nhập bằng gói thuê bao

claude_code, OpenAI-Codex (ChatGPT, đăng nhập bằng mã thiết bị), ChatGPT Native OAuth, Kimi Code

Chạy local

Ollama (ollama_model_name), hoặc bất kỳ endpoint tương thích OpenAI

Đọc app/models/llm_provider.py và phần LLM trong config.example.toml. Đổi config.toml sang dùng DeepSeek: tôi sẽ tự điền deepseek_api_key, bạn chỉ sửa llm_provider. Sau đó chạy cli.py --stop-at script với chủ đề thử để kiểm tra kết nối. Không in key ra màn hình.

10Giọng đọc và nhạc nền

Giọng đọc (TTS)

  • Edge TTS (miễn phí, không cần key; trong WebUI tên là “Azure TTS V1”). Giọng tiếng Việt: vi-VN-HoaiMyNeural-Female, vi-VN-NamMinhNeural-Male. Danh sách đầy đủ: docs/voice-list.txt.
  • Các provider khác dùng tiền tố: gemini:, mimo:, elevenlabs:, chatterbox:, kokoro:, voxcpm:. Ngoài ra còn Azure TTS V2, SiliconFlow, MiniMax, Fish Audio (cấu hình trong các mục [azure], [siliconflow], [minimax_tts], [elevenlabs], [fish_audio], [voxcpm]…).
  • --voice-name no-voice: video không lồng tiếng. --custom-audio-file: dùng giọng bạn tự thu.
  • ElevenLabs: tốc độ đọc phụ thuộc model. eleven_multilingual_v2 cho phép 0.7–1.2×, eleven_v3 cho phép 0.25–4.0×.

Nhạc nền

  • random (mặc định): chọn ngẫu nhiên trong resource/songs.
  • custom + --bgm-file: file trong storage/bgm hoặc resource/songs.
  • sonilo / elevenlabs: nhạc do AI sáng tác, đi kèm --video-music-prompt "lofi, nhẹ nhàng". Key lấy từ config.toml hoặc SONILO_API_KEY / ELEVENLABS_API_KEY.
  • none: không có nhạc nền.
Tôi có file giong-doc.mp3 tự thu. Tạo video 9:16 dùng --custom-audio-file giong-doc.mp3, bật subtitle_provider = "whisper" trong config.toml để phụ đề khớp giọng thật (hỏi tôi trước khi sửa config), nhạc nền AI bằng elevenlabs với prompt "piano ấm áp", bgm-volume 0.15.

14Dự án video có phiên bản (chỉnh từng cảnh)

Tính năng chạy hoàn toàn local, không gọi API và không tự đăng bài. Chi tiết: docs/video-projects.md.

Đọc docs/video-projects.md. Từ task storage/tasks/<id> vừa tạo, dựng episode.json với mỗi đoạn là một scene (giữ id ổn định). Sau đó thay footage của scene "opening" bằng ./new-opening.mp4, chạy revise → plan (giải thích bước nào sẽ build lại) → render.

15Tối ưu Claude Code cho MoneyPrinterTurbo

15.1 CLAUDE.md cho dự án

Tạo CLAUDE.md ở thư mục gốc repo để Claude luôn nhớ quy ước của bạn:

CLAUDE.md# Quy ước làm video
- Luôn chạy bằng: uv run python cli.py ...
- Mặc định: --video-language vi --voice-name vi-VN-HoaiMyNeural-Female
  --font-name BeVietnamPro-Bold.ttf --video-aspect 9:16
  --subtitle-display-mode word_by_word --subtitle-animation pop_spring
- Không bao giờ in nội dung config.toml hoặc API key.
- Không thêm cờ --confirm-*-charge khi tôi chưa đồng ý chi phí.
- Không bật upload_post_auto_upload khi chưa hỏi.
- Kết quả: báo task_id và đường dẫn final-*.mp4 trong storage/tasks/.

15.2 Slash command riêng

Tạo .claude/commands/video.md, rồi gõ /video Chủ đề của bạn:

.claude/commands/video.md---
description: Tạo video ngắn tiếng Việt bằng MoneyPrinterTurbo
argument-hint: <chủ đề>
---
1. Chạy `uv run python cli.py --video-subject "$ARGUMENTS" --stop-at script`
   theo quy ước trong CLAUDE.md và cho tôi xem kịch bản.
2. Chờ tôi duyệt hoặc sửa, rồi render bằng --video-script.
3. Báo đường dẫn video và tóm tắt (thời lượng, giọng, nguồn footage).

15.3 Giảm hỏi quyền lặp lại

.claude/settings.json{
  "permissions": {
    "allow": [
      "Bash(uv run python cli.py:*)",
      "Bash(uv run python main.py:*)",
      "Bash(python -m app.services.video_project:*)"
    ],
    "deny": ["Read(./config.toml)"]
  }
}
Lưu ý về deny Read(config.toml)Quy tắc này ngăn Claude đọc file chứa key. Bỏ nó đi nếu bạn muốn Claude tự chỉnh cấu hình giúp mình.

15.4 Tự động hoá không cần tương tác

claude -p "Tạo video về 'Tin công nghệ nổi bật tuần này' theo CLAUDE.md, in đường dẫn MP4" \
  --allowedTools "Bash(uv run python cli.py:*)" "Read" "Write"

Kết hợp với cron hoặc lệnh /loop của Claude Code để sản xuất định kỳ, ví dụ mỗi sáng một video.

15.5 Chia việc cho subagent

Dùng subagent để nghiên cứu và viết 10 kịch bản (mỗi kịch bản khoảng 120 từ, tiếng Việt, có câu mở đầu gây tò mò) về chủ đề "sức khoẻ tinh thần". Gom lại thành tasks.json, trong đó mỗi task dùng video_script (không cần LLM của MPT), rồi chạy batch.

15.6 Phát triển và mở rộng MPT

Repo có bộ test trong test/. Hãy để Claude thêm tính năng mới (ví dụ một nguồn footage hoặc provider TTS mới) và chạy uv run python -m pytest test/services -q để kiểm tra. 17Bảo mật và chi phí

  • Key: chỉ lưu trong config.toml (đã có trong .gitignore); không dán key vào issue hay commit. Skill được thiết kế để không bao giờ in key ra.
  • Chi phí AI video: mỗi clip tạo bằng Seedance, WaveSpeed, OFox, MiniMax, MuAPI, Infistar hay Jalapeno là một task tính phí. Hãy để Claude ước tính số clip (≈ thời lượng ÷ video_clip_duration) trước khi xác nhận.
  • Gói Claude: provider claude_code tiêu hao hạn mức gói thuê bao. Khi chạy batch lớn, cân nhắc model nhẹ hơn hoặc viết kịch bản sẵn.
  • API công khai: luôn đặt api_key nếu mở cổng 8080 ra ngoài; Docker compose mặc định chỉ bind 127.0.0.1.
  • Bản quyền: nhạc mẫu trong resource/songs lấy từ YouTube. Nếu đăng thương mại, hãy thay bằng nhạc bạn có quyền sử dụng.

18Thư viện prompt dùng ngay

Video giáo dục 16:9 từ kịch bản viết sẵn

Viết kịch bản khoảng 200 từ giải thích "Vì sao bầu trời màu xanh" cho học sinh cấp 2, giọng văn vui. Cho tôi duyệt. Sau đó render bằng --video-script, khổ 16:9, giọng vi-VN-NamMinhNeural-Male, phụ đề ở dưới, chuyển cảnh fade-in, --video-clip-duration 4.

Nhân bản nội dung đa ngôn ngữ

Từ chủ đề "Ẩm thực đường phố Sài Gòn", tạo 3 video: tiếng Việt (vi-VN-HoaiMyNeural-Female), tiếng Anh (en-US-JennyNeural-Female), tiếng Nhật (ja-JP-NanamiNeural-Female). Dùng batch-file với video_language và voice_name riêng cho từng task. Kiểm tra tên giọng trong docs/voice-list.txt trước.

Tạo tiêu đề và mô tả để đăng bài

Khởi động API, gọi POST /api/v1/social-metadata cho kịch bản của task vừa tạo để lấy tiêu đề, mô tả và hashtag phù hợp TikTok bằng tiếng Việt. Ghi kết quả vào output/metadata.md.

Chạy thử mà không tốn tiền

Chạy thử với --stop-at audio cho chủ đề "Mẹo ngủ ngon" để kiểm tra LLM và giọng đọc mà chưa tải footage. Báo thời lượng file audio, rồi hỏi tôi có muốn tiếp tục render không.
